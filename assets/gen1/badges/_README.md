# assets/badges/

Ikony 8 gym odznaků. Na rozdíl od trenérů/leaderů jde o **ploché soubory**
(ne složky): `assets/badges/<id>.png`. Doporučená velikost ~64–128 px, průhledné pozadí.

Soubory (id = kanonické jméno odznaku):
- `boulder-badge.png` (Brock) · `cascade-badge.png` (Misty)
- `thunder-badge.png` (Lt. Surge) · `rainbow-badge.png` (Erika)
- `soul-badge.png` (Koga) · `marsh-badge.png` (Sabrina)
- `volcano-badge.png` (Blaine) · `earth-badge.png` (Giovanni)

Chybějící ikona → fallback. Kód nic neregistruje, stačí nahrát soubor.
